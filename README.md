### Вторая и третья лабораторная по вычислительной геометрии(плюс доп задание - булевы функции)
Построение Octree для объектов:
- Шар
- Куб
Выполнение булевых операций:
- вычитание - difference
- объединение - union
- пересечение - intersection
Вычисление объема.

## Для сдачи необходимо реализовать визуальный интерфейс чтобы выполнять функции:
#### Для второй лабораторной работы:
  - Возможность задавать шар его радиус и центер
  - Возможность задавать параллелепипед, максимальные и минимальные координаты
#### Для третьей лабораторной работы:
  - кнопка, рассчитать объем и отображение объема
#### Доп задание для второй и третьей лабораторной работы:
  - возможность выбрать булеву операции и задать объекты над которыми выполняется операция
  - возможность изменять порядок объектов для булевых операций

Всё что нужно реализовано в текущем коде, осталось сделать удобный интерфейс. 

Примеры вызова функций есть в main.py

 #### Структура
 - node.py - класс Node в котором описан узел
 - octree.py - класс Octree в котором описано создание Octree
 - visualizer.py - класс Visual для собрания сетки и отображения объектов
 - main.py - для выполнения функций(в нем должен быть реализован интерфейс пользователя, либо создать отдельный класс а в main вызов)
